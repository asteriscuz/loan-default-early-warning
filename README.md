# Loan Default Early-Warning System

An end-to-end machine learning project to predict vehicle loan defaults using the L&T Vehicle Loan Default dataset.

**Dataset:** [L&T Vehicle Loan Default Prediction — Kaggle](https://www.kaggle.com/c/ltfs-fin-hack/data)

## Project Status

**Work in Progress**

The project will compare classical machine learning models using random and out-of-time validation, followed by model evaluation, experiment tracking, and deployment.

## Tools

Python, Pandas, scikit-learn, XGBoost, LightGBM, MLflow, FastAPI, Docker.
